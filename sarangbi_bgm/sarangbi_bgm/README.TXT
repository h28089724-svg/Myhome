사랑비 BGM ver 2.1 입니다.

이 프로그램을 사용하기 위해서는 계정이 PHP 와 MYSQL 을 지원해야 합니다.


처음 설치
=========
1. 사랑비 BGM 을 다운로드 하여 압축을 풀고 여러분의 계정에 업로드 합니다.
2. 사랑비 BGM 을 업로드 한 디렉토리의 권한을 707 혹은 777 로 변경합니다.
3. 웹브라우저에서 install.php 를 실행합니다.
   http://사랑비BGM경로/install.php


업그레이드
==========
1. 사랑비 BGM 을 다운로드 하여 압축을 풀고 기존의 사랑비 BGM ver 2.0 이 설치된
   디렉토리에 덮어 쉬웁니다.
2. 웹브라우저에서 upgrade.php 를 실행합니다.
   http://사랑비BGM경로/upgrade.php


보다 자세한 도움말은 http://www.sarangbi.net 에서 제공합니다.
